# Yeshi Chophel Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the `#` LinkedIn and GitHub links in `index.html` with your actual profile URLs.
2. If you want a profile photo, we can add one to the hero section.
3. Add project/certification links when you have the actual URLs.
4. `profile.png` is the supplied profile photo and `Yeshi_Chophel_CV.pdf` is the supplied CV.

## Deploy on Netlify
- Create a GitHub repository and upload these three files.
- In Netlify, choose **Add new project / Import an existing project** and select the GitHub repository.
- This is a static site, so the publish directory is the repository root and no build command is required.
